# QuestRoute

《魔兽世界：无限》任务规划与地图导航插件。结合当前任务和 QuestieDB 关联，推荐顺路接取、优先前置及同区合做，在原生两张地图显示路线和热点，并为已接任务怪提供姓名板提示。

## 安装

1. 完整退出游戏。
2. 将仓库中的整个 `addons/QuestRoute` 文件夹复制到游戏的 `Interface/AddOns/`，最终为 `Interface/AddOns/QuestRoute/`。保留 `QuestRoute.toc` 及其列出的全部 Lua 文件。
   - 若在本机源码仓库上开发，不要复制，改用目录联接让安装指向仓库，编辑即生效：
     ```powershell
     cmd /c mklink /J "<游戏>\Interface\AddOns\QuestRoute" "<仓库>\addons\QuestRoute"
     ```
3. 需要沿用旧配置时，先按下方步骤迁移，再启动游戏；在插件列表中确认启用 QuestRoute。

插件目录改名、增加文件或修改 `.toc` 后，必须完整退出并重新启动游戏，`/reload` 不够。

原生客户端数据决定角色状态与进度；可选安装 QuestieDB 补充任务链、附近与目的地相关任务、启动物品、目标实体和静态地点。插件可以独立运行，无限工坊用于开发调试与 API 调用。

## 使用

- 大地图显示本图路线，小地图显示附近路线；橙色 1 号表示下一步，`N?` 表示可交任务，`N~` 表示已完成但交付状态待确认，`N!` 表示接取/物品启动。
- 每个可靠识别的未完目标有一个主热点和最多两个紫色 `Nb/Nc` 备选；备选不计入路线步数或里程。
- 地图标记右键跳过整项任务，Shift + 右键切换该目标地点。
- 悬停最多四行（含标题），显示任务名、目标进度、简短状态（含距离）与位置性质、操作说明。
- 当前 1 号自动改变或本图做完时，屏幕上方会有一行轻提示；可用 `/questroute notice off` 关闭。
- 玩家自行开启敌方姓名板（默认 `V`）后，相关任务怪显示黄色击杀/材料提示，当前路线目标为橙色。

常用命令：

| 命令 | 作用 |
| --- | --- |
| `/questroute on`、`/questroute off` | 开启或关闭路线与任务标识 |
| `/questroute replan` | 立即重新选择下一步 |
| `/questroute unskip all` | 恢复所有手动跳过的任务 |
| `/questroute nextspot` | 为当前目标换地点 |
| `/questroute resetspots` | 清除临时地点避让 |
| `/questroute nameplates on`、`/questroute nameplates off` | 单独控制姓名板提示 |
| `/questroute notice on`、`/questroute notice off` | 同时开关屏幕与聊天框提示（默认开） |
| `/questroute monsterlevel 0..5` | 设置怪物最多高出角色几级，默认2；0为不高于自身，只检查怪物等级 |
| `/questroute minlevel 0..60` | 接取建议最低任务等级，默认15；0关闭，已接任务不受影响 |
| `/questroute why` | 查看路线理由、漏接/附近/物品任务机会和索引进度，本图做完时给出下一张地图 |
| `/questrouteapi` | 只读显示当前任务列表 |

完整命令与公开 API 见[插件 README](addons/QuestRoute/README.md)。

## 设置

在游戏中打开 **选项 → 插件 → QuestRoute**，有三个复选框和两个等级滑条：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| 将精英任务加入路线规划 | 关 | 未完成精英任务可参与当前地图规划 |
| 目标变化时显示屏幕提示 | 开 | 1 号自动变化或本图做完时上方一行提示 |
| 在任务怪姓名板上显示提示 | 开 | 你自行打开的敌方姓名板上标出相关任务怪 |
| 怪物最多高出角色几级 | 2 | 0..5整数；0只安排同级及以下怪物，1允许高1级；不按任务等级过滤 |
| 接取建议最低任务等级 | 15 | 0..60整数；低于阈值的未接任务不显示，0关闭，等级未知保留 |

未接的重复、战场/PvP、节日/安其拉筹备活动、捐献类和纯英文标题不显示接取建议及标记；已接任务继续导航和交付。新增最低等级滑条需重载界面后在设置页显示，也可直接用minlevel命令调整。

默认关闭的精英开关打开后，未完成精英任务可参与当前地图规划。副本、专业、失败、手动跳过、外图及无可靠位置的过滤继续生效；已完成任务仍可顺路交付。

选项按服务器与角色保存，切换后立即重排，正常退出或重载界面时由游戏写盘。设置页使用原生勾选框和滑条；滑条改值立即重排，不会改变任务跳过记录。

## 离线验证

安装 Python 与 `lupa` 后，在仓库根目录执行：

```powershell
python -m pip install lupa
python tests/verify_quest_data.py
python tests/verify_associations.py
```

验证在隔离的 Lua 5.1 环境按 `.toc` 顺序加载整个插件，不连接或修改游戏。`--addon` 可指定插件目录或 `.toc`；旧的 `--addon addons/QuestRoute/QuestRoute.lua` 写法也会加载同目录的完整清单。按改动范围选择检查见[开发约定](addons/QuestRoute/AGENTS.md)；纯文档修改只检查链接、引用和差异。
